# LearnMate — Cinematic Learning Studio

A front-end major-project prototype made with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open the `LearnMate-Cinematic` folder in VS Code.
3. Open `index.html` with Live Server (recommended), or open it directly in a browser.
4. Enter any name and valid email to enter the dashboard.

## Features
- Cinematic split-screen login / welcome experience.
- Responsive dashboard with cream, espresso brown, lilac and powder-blue palette.
- Four working sections: Overview, My Learning, Quiz Studio and My Progress.
- Three learning paths with interactive progress updates.
- Offline quiz question sets for JavaScript, HTML/CSS and Computer Science.
- Score calculation, answer review and quiz history summary.
- Browser localStorage keeps the demo profile and progress after refresh.

## Important prototype notes
- This is a front-end demonstration. The login screen is not secure authentication and does not verify email/password.
- Quiz questions are local sample data, not generated by a live AI API.
- Progress is stored in the current browser only. Clearing browser data resets it.
- Google Fonts requires an internet connection; fallback fonts are provided.
- To turn this into a production app, add a backend/auth provider, database, real lesson content and a protected AI API integration.
